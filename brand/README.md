# Brand

The swift-institute mark: the Swift Institute four-bar pyramid (80/160/240/320 bar
widths, the same geometry as the social-card glyph in
swift-institute/.github `social-preview/glyph-pyramid.svg`) on the warm-white
ground `#fbf8f6`, with this org's accent: pale gold #fbe8b2 → #ecd08a (top bar).

| File | Use |
|------|-----|
| `avatar.svg` | Vector source of the org avatar. |
| `avatar-1024.png` | Raster export for the GitHub org-avatar uploader (raster only). |

Provenance: the original avatar SVG sources lived under
`swift-institute.org/avatars/` and were lost with the website repository's
pre-recovery history. Reconstructed 2026-08-03 by exact measurement of the
live org avatar (geometry, ground, neutral ramp, and accent gradient read
from the served 460×460 image; interiors verified within 5/255 per channel,
residual differences are bar-edge antialiasing only). Recovery recorded in
swift-institute/.github#259.
